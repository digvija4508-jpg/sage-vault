Questions about installing Overwork

The release notes and every past installer are on GitHub.

Read the release notes

Do I need a paid API key?

No. The default models are the free ones from Kilo and OpenCode Zen.

Can I install Overwork over an older version?

Yes. Run the new installer; it replaces the app and keeps your documents.

Why does Windows warn me about the file?

The installer is not code-signed yet. Choose More info, then Run anyway.

Does Overwork need admin rights?

No. It installs under your own Windows user, in AppData.

Which models does Overwork use by default?

Kilo's free auto model and the free OpenCode Zen models. You pick the model for each task.

What stays if I uninstall Overwork?

Your documents stay. The app, its tools and its PATH entry are removed.

Install Overwork on your PC

Version 0.2.0, 421 MB, for Windows 10 and 11.
